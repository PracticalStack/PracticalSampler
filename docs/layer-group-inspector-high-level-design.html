Authoring UX · Focused redesign

Layer and Group Inspector

Replace the alternating Layer and Group editors with a persistent Instrument Structure browser and one context-sensitive property inspector. The lower Waveform and Groups tabs stop controlling which hierarchy editor is visible.

Status: ProposedScope: Focused foundation for the unified workspaceDate: 21 August 2026Related: Unified Instrument Workspace HLD
Core decision. The left side becomes navigation only. The right side becomes editing only. Workbench tabs change the specialized tool below the map, never the hierarchy browser or the inspector selection.
01 · Problem and correction

Stop making the tab bar choose the hierarchy UI

Current behavior

Layer and Group controls compete for the same cramped left-side area. The visible editor appears to change with Waveform/Groups context, selection is hard to understand, and the map loses space to rows of fields.

Proposed behavior

A compact tree always shows Instrument → Layer → Group → Zone. Selecting a node changes one right-side inspector. Waveform and Groups remain specialized lower workbenches and do not replace either surface.

02 · Placement

Persistent browser, map, context inspector

03 · Instrument Structure browser

A compact tree with predictable actions

Layer selectedRight inspector becomes Layer. + Group is enabled and creates beneath the selected layer.
Group selectedRight inspector becomes Group. + Zone is enabled and creates beneath the selected group.
Zone selectedRight inspector becomes Zone. Map selection and waveform context follow the zone.
ElementBehavior
Instrument rowRoot of the tree; cannot be deleted or reordered. Disclosure expands/collapses the hierarchy.
Layer rowName plus group/zone counts and aggregate key coverage. Selecting it does not change the active workbench tab.
Group rowStable group tint, name, key/velocity summary, and zone count. Children are its zones.
Zone rowSample display name, root/note identity, and velocity summary. Selecting it reveals the zone in Map.
DisclosureChanges presentation state only; it does not change selection or dirty the project.
Search/filterMatches layer, group, zone, or sample name. Ancestors remain visible so the path is never lost.
Action toolbarTwo rows preserve readable labels at 224 px. Invalid actions are disabled with a tooltip rather than silently retargeted.
Context menuRename, duplicate, move/reassign, reveal, audition, and delete commands appropriate to the selected type.
04 · Property inspectors

Real controls with one consistent structure

Layer inspector

  • Header: type, name, path, audition, select groups, overflow.
  • Identity: name, visibility, authored order.
  • Mix & routing: gain, pan, output bus, audition anchor group.
  • Crossfade: source, controller, window, direction, curve.
  • Read-only summary: group count, zone count, aggregate coverage, effective output.

Group inspector

  • Header: type, name, path, audition, select zones, overflow.
  • Identity: name, parent layer, visibility, authored order.
  • Mix & routing: gain, pan, output bus, audition anchor zone.
  • Playback: round-robin enabled and mode.
  • Read-only summary: zone count, aggregate coverage, effective layer/group mix.
Editing rule. Every value in an editable section is a real JUCE control connected to an AuthoringSession transaction. Selection never dirties the project. Text/numeric controls commit on Enter or focus loss, toggles and combos commit immediately, and a slider gesture creates one undo step.

06 · Responsive behavior

Preserve Map width at the compact shell

Expanded · 1120 px

Tree 224–248 px, map consumes the middle, right inspector 320–360 px. Both side surfaces are user-collapsible.

Compact · 820 px

Tree 206–224 px remains visible. The inspector becomes a 292 px right drawer over Map and closes with Escape.

Maximum Map

The tree collapses to a 32 px Structure rail. The inspector collapses completely. Both restore the current selection when reopened.

Session context

Select layer, group, or zone without an edit transaction or automatic tab switch.

Inspector commit

Validated batch/session method commits one authored transaction and refreshes all views.

Performance boundary

  • Use a flattened virtual row model; do not create an editor component per tree node.
  • Collapsed descendants do not enter the visible row vector.
  • Search and expansion rebuild lightweight rows from existing hierarchy projections.
  • Keep controls exclusively in the right inspector so a 1,700-zone project does not create 1,700 JUCE control trees.
  • Preserve selected and expanded stable IDs across refresh, undo/redo, filtering, and project reload.

09 · Acceptance criteria

This focused redesign is complete when

  1. The left side shows one Instrument Structure browser in both Waveform and Groups workbench states.
  2. The tree exposes Instrument → Layer → Group → Zone with disclosure, search, stable group tint, and readable metadata.
  3. Selecting a layer or group from Map changes one right-side inspector without switching workbench tabs.
  4. Layer and Group inspectors contain real editable controls and clearly separated read-only summaries.
  5. Create, duplicate, rename, reorder/reassign, and delete actions target the selected entity deterministically.
  6. Waveform and Groups tabs update only the lower workbench and never replace the tree or inspector.
  7. The 1120 px layout fits persistent tree and inspector; the 820 px layout uses an inspector drawer and preserves usable Map width.
  8. Selection, expansion, and search survive refresh by stable ID and do not dirty the project.
  9. Keyboard and screen-reader users can traverse the full hierarchy and reach every action.
  10. The 1,700-zone responsiveness baseline remains within budget.
