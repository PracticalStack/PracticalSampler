Engineering review · implementation iteration

Groups now own Round Robin as a single, predictable contract.

The Groups workflow has been realigned around layered instruments and Kontakt-style group behavior: groups remain independent mix/routing layers, while Round Robin is enabled for an entire group only when every zone can participate in a valid mapping pool.

Outcome

The old anchor-owned, partial-pool workflow has been replaced in the Groups inspector by one Round Robin toggle and a Cycle / Random mode selector. A group can contain several independent mappings—for example, one pool per key or velocity layer—but no zone may remain outside Round Robin while the group toggle is on.

Layering remains intact

Pad, pluck, and other layers continue to live in separate groups. Each group retains its own gain, pan, visibility, routing-bus ownership, audition anchor, and zone membership. That is the intended seam for future per-group DSP chains.

The group Round Robin invariant

1 · Gather membersInspect every zone assigned to the selected group.
2 · Partition mappingsGroup exact matches by articulation, root/range, velocity, crossfade, and trigger mode.
3 · Qualify all zonesEvery mapping partition must contain at least two zones.
4 · Build poolsAssign complete, one-based slots to every zone using one uniform mode.
5 · Guard editsIf an edit creates a singleton mapping, clear RR across the whole group.

Behavior when a zone breaks the rule

  1. The edit itself is preserved as a normal undoable authoring transaction.
  2. All Round Robin descriptors in the affected group are removed.
  3. The group toggle reports Off.
  4. A re-enable attempt is rejected.
  5. The warning names the zone IDs that need to be removed or corrected.

Cycle and Random

  • Cycle advances 1 → 2 → … → N → 1 independently for each mapping pool.
  • Random uses bounded, allocation-free pool state in the realtime sampler path.
  • Mode is serialized in project, snapshot, and prepared-playback JSON.
  • Legacy scalar Round Robin data remains sequential.

Bug fixed: schema-4 import

Importing content into a current group project with any Round Robin metadata previously attempted the older Phase-3 migration and could reject the edit. Migration is now limited to genuinely older schemas.

Bug fixed: mode loss

Pool normalization previously rewrote every descriptor to sequential. Normalization now preserves an existing mode, and group rebuilds apply the explicitly selected mode.

Compatibility seam

The older group-pool transaction methods remain callable, but now delegate to the all-or-nothing group behavior so hidden callers cannot recreate partial group pools.

Definition used for “qualifies”

Two zones qualify as alternates when group, articulation, root key, key range, velocity range, velocity-crossfade descriptor, and trigger mode match. Different playable mappings may coexist in one group; each mapping must independently contain at least two alternates. Sample identity, gain, pan, loop points, and release are intentionally allowed to differ.
