# Contributing to Practical Sampler

Practical Sampler is an AI development project with two goals:

- Create a free, open-source sampler with first-class instrument-authoring features.
- Test the limits of AI-assisted software development on a substantial, real-world product.

The project was developed with OpenAI models: ChatGPT 5.4 contributed approximately 60% of the work,
with SOL and LUNA contributing approximately 40%.

## Before contributing

Code submitted for inclusion should either align with the
[project roadmap](https://practicalsampler.com/practical-sampler-v1-roadmap.html)
or address a [tracked issue](https://github.com/PracticalStack/PracticalSampler/issues). Please keep
changes focused and include appropriate tests or validation for the behavior being changed.

All submitted code will be reviewed by SOL, or by a higher-capability OpenAI model released in the
future, before it is accepted.
